# 시스템 관제 자동화 스크립트 개발 수행 내역서

## 1. 제출 산출물

- 요구사항 수행 내역서: `최종결과물/docs/요구사항_수행내역서.md`
- 자동화 스크립트: `최종결과물/scripts/monitor.sh`
- 실제 배치 경로: `$AGENT_HOME/bin/monitor.sh`

## 2. 기준 환경

- OS: Ubuntu 22.04 LTS 또는 동등 리눅스 환경
- AGENT_HOME: `/home/agent-admin/agent-app`
- AGENT_PORT: `15034`
- AGENT_UPLOAD_DIR: `$AGENT_HOME/upload_files`
- AGENT_KEY_PATH: `$AGENT_HOME/api_keys/t_secret.key`
- AGENT_LOG_DIR: `/var/log/agent-app`
- SSH Port: `20022`
- APP Port: `15034`
- 방화벽: UFW 기준

## 4. 기본 보안 및 네트워크 설정

### SSH 포트 변경 및 Root 원격 접속 차단

수행 명령:

```bash
sudo cp /etc/ssh/sshd_config /etc/ssh/sshd_config.bak
sudo sed -i 's/^#\?Port .*/Port 20022/' /etc/ssh/sshd_config
sudo sed -i 's/^#\?PermitRootLogin .*/PermitRootLogin no/' /etc/ssh/sshd_config
sudo systemctl restart ssh
```

확인 명령:

```bash
sudo sshd -T | grep -E '^(port|permitrootlogin)'
sudo ss -tulnp | grep ':20022'
```

증거 기록:

```text
[붙여넣기] port 20022 확인 결과
[붙여넣기] permitrootlogin no 확인 결과
[붙여넣기] sshd 20022 LISTEN 확인 결과
```

### UFW 방화벽 활성화 및 허용 포트 제한

수행 명령:

```bash
sudo ufw default deny incoming
sudo ufw default allow outgoing
sudo ufw allow 20022/tcp
sudo ufw allow 15034/tcp
sudo ufw enable
```

확인 명령:

```bash
sudo ufw status numbered
```

증거 기록:

```text
[붙여넣기] UFW active 확인 결과
[붙여넣기] 20022/tcp ALLOW 확인 결과
[붙여넣기] 15034/tcp ALLOW 확인 결과
```

## 5. 계정/그룹/권한 체계

### 계정 및 그룹 생성

수행 명령:

```bash
sudo groupadd agent-common
sudo groupadd agent-core

sudo useradd -m -s /bin/bash agent-admin
sudo useradd -m -s /bin/bash agent-dev
sudo useradd -m -s /bin/bash agent-test

sudo usermod -aG agent-common,agent-core agent-admin
sudo usermod -aG agent-common,agent-core agent-dev
sudo usermod -aG agent-common agent-test
```

확인 명령:

```bash
id agent-admin
id agent-dev
id agent-test
getent group agent-common
getent group agent-core
```

증거 기록:

```text
[붙여넣기] id agent-admin 결과
[붙여넣기] id agent-dev 결과
[붙여넣기] id agent-test 결과
[붙여넣기] agent-common / agent-core 그룹 결과
```

### 디렉토리 및 권한 설정

수행 명령:

```bash
export AGENT_HOME=/home/agent-admin/agent-app

sudo mkdir -p "$AGENT_HOME/bin"
sudo mkdir -p "$AGENT_HOME/upload_files"
sudo mkdir -p "$AGENT_HOME/api_keys"
sudo mkdir -p /var/log/agent-app

sudo chown -R agent-admin:agent-core "$AGENT_HOME"
sudo chown agent-admin:agent-common "$AGENT_HOME/upload_files"
sudo chown agent-admin:agent-core "$AGENT_HOME/api_keys"
sudo chown agent-admin:agent-core /var/log/agent-app

sudo chmod 750 "$AGENT_HOME"
sudo chmod 770 "$AGENT_HOME/upload_files"
sudo chmod 770 "$AGENT_HOME/api_keys"
sudo chmod 770 /var/log/agent-app

sudo setfacl -m g:agent-common:rwx "$AGENT_HOME/upload_files"
sudo setfacl -m g:agent-core:rwx "$AGENT_HOME/api_keys"
sudo setfacl -m g:agent-core:rwx /var/log/agent-app
```

확인 명령:

```bash
ls -ld "$AGENT_HOME" "$AGENT_HOME/upload_files" "$AGENT_HOME/api_keys" /var/log/agent-app
getfacl "$AGENT_HOME/upload_files" "$AGENT_HOME/api_keys" /var/log/agent-app
```

증거 기록:

```text
[붙여넣기] ls -ld 디렉토리 권한 결과
[붙여넣기] getfacl ACL 결과
```

## 8. monitor.sh 구현 요약

- 프로세스 헬스 체크: `agent_app.py` 실행 여부 확인, 실패 시 `exit 1`
- 포트 헬스 체크: TCP `15034` LISTEN 여부 확인, 실패 시 `exit 1`
- 방화벽 점검: UFW 또는 firewalld 활성 상태 확인, 비활성 시 `[WARNING]` 출력
- 자원 수집: CPU 사용률, 메모리 사용률, 루트 파티션 디스크 사용률
- 임계값 경고: CPU `20%`, MEM `10%`, DISK_USED `80%` 초과 시 `[WARNING]`
- 로그 기록: `/var/log/agent-app/monitor.log`
- 로그 포맷: `[YYYY-MM-DD HH:MM:SS] PID:... CPU:..% MEM:..% DISK_USED:..%`
- 로그 용량 관리: `monitor.log`가 10MB 이상이면 `monitor.log.1`부터 최대 10개까지 순환 보관

## 9. cron 자동 실행 설정

수행 명령:

```bash
sudo -u agent-admin crontab -l > /tmp/agent-admin.cron 2>/dev/null || true
echo '* * * * * /home/agent-admin/agent-app/bin/monitor.sh >> /var/log/agent-app/monitor.cron.out 2>&1' >> /tmp/agent-admin.cron
sudo -u agent-admin crontab /tmp/agent-admin.cron
rm -f /tmp/agent-admin.cron
```

확인 명령:

```bash
sudo -u agent-admin crontab -l
tail -n 5 /var/log/agent-app/monitor.log
sleep 70
tail -n 5 /var/log/agent-app/monitor.log
```

증거 기록:

```text
[붙여넣기] agent-admin crontab 매분 실행 등록 결과
[붙여넣기] 1분 전 monitor.log 라인
[붙여넣기] 1분 후 monitor.log 증가 확인 결과
```

## 10. 필수 증거 자료 체크리스트

- [ ] SSH 포트 `20022` 변경 확인
- [ ] Root 원격 접속 차단 `PermitRootLogin no` 확인
- [ ] 방화벽 활성화 확인
- [ ] 방화벽 `20022/tcp`, `15034/tcp`만 허용 확인
- [ ] 계정 `agent-admin`, `agent-dev`, `agent-test` 생성 확인
- [ ] 그룹 `agent-common`, `agent-core` 생성 및 멤버십 확인
- [ ] `upload_files`, `api_keys`, `/var/log/agent-app` 권한 및 ACL 확인
- [ ] 앱 Boot Sequence 5단계 `[OK]` 확인
- [ ] `Agent READY` 확인
- [ ] 앱 `0.0.0.0:15034` LISTEN 확인
- [ ] `monitor.sh` 실행 결과 확인
- [ ] `/var/log/agent-app/monitor.log` 누적 기록 확인
- [ ] `agent-admin` crontab 매분 실행 등록 확인
- [ ] 1분 후 `monitor.log` 자동 증가 확인

## 11. 제출 전 최종 점검 명령

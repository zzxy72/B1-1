# B1-1 최종 결과물

이 폴더는 `요구사항/b1-1.md`를 분석해 작성한 제출 결과물입니다.

## 구성

```text
최종결과물/
  README.md
  docs/
    요구사항_수행내역서.md
  scripts/
    monitor.sh
```

## 제출 전 확인

```bash
bash -n 최종결과물/scripts/monitor.sh
chmod +x 최종결과물/scripts/monitor.sh
```

실제 서버 적용 후 `docs/요구사항_수행내역서.md`의 증거 기록 영역에 명령 출력 결과를 채우면 제출용 수행 내역서로 사용할 수 있습니다.
